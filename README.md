# E-Commerce Micro-Frontend Application

A modular e-commerce platform built with micro-frontend architecture using Module Federation.

## Architecture

- **Host App**: Main application shell (port 3000)
- **Products Remote**: Product listing module (port 3001)
- **Basket Remote**: Shopping basket module (port 3002)

## Technologies

- Next.js
- React
- TypeScript
- Module Federation
- Redux Toolkit & RTK Query
- Ant Design

## Setup Instructions

### Prerequisites
- Node.js 18+
- npm or yarn
